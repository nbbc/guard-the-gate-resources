# Guard the Gate — Tools & Setup Guides

A static, mobile-friendly resource page for the **Guard the Gate** pamphlet and talk. It summarizes a layered approach to online safety and links to current first-party setup guidance.

## Protection stack

- CleanBrowsing Family Filter — home-network DNS filtering
- Firewalla — whole-home router and firewall controls
- Canopy — device-level filtering
- Covenant Eyes — personal accountability
- Built-in Apple, Google, Xbox, PlayStation, Nintendo, and YouTube controls
- Family rules and regular conversation

## Updating the page

The site uses plain HTML and CSS with no build process or tracking scripts.

1. Edit `index.html` for copy or links.
2. Edit `styles.css` for design changes.
3. Verify third-party links and the “reviewed” date before publishing.

GitHub Pages serves the repository root from the `main` branch.
